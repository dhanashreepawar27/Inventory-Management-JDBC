# Inventory Management System

## Overview
The Inventory Management System is a Java-based application developed using **JDBC** to perform basic inventory operations. It helps manage product details by storing and retrieving data from a MySQL database.

## Features
- Add Product
- View Products
- Update Product Details
- Delete Product
- Search Product

## Technologies Used
- Java
- JDBC
- MySQL
- Eclipse IDE
